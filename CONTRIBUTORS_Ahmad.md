## 🤝 Comment Contribuer

### Pour Ahmad et futurs contributeurs:

1. **Avant de commencer:**
   - Consultez le CHANGELOG.md pour comprendre les changements existants
   - Lisez la documentation des composants (TOAST_USAGE.md, MODAL_CONFIRMATIONS.md, etc.)
   - Vérifiez les patterns et conventions utilisés

2. **Lors de l'implémentation:**
   - Maintenez la cohérence du design moderne
   - Utilisez les composants réutilisables existants
   - Testez sur tous les navigateurs/appareils
   - Documentez les changements

3. **Avant de commiter:**
   - Exécutez: `npm run build`
   - Testez les fonctionnalités touchées
   - Mettez à jour CHANGELOG.md

4. **Format du commit:**
   ```
   git commit -m "description des changements

   Détails supplémentaires si nécessaire"
   ```
